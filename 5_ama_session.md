## 1. What is a higher-order function in JavaScript?

A higher-order function is a function that takes another function as an argument or returns a function.

## 2. Which operator is used to create a shallow copy?

The spread operator (`...`) is commonly used to create a shallow copy of an object or array.

## 3. What is destructuring?

Destructuring is a JavaScript feature used to extract values from objects or arrays and store them in variables.
```js
const user = {
  name: "Atul",
  age: 22,
};

const { name, age } = user;
```

## 4. How do you change `innerHTML`?

We can change `innerHTML` by assigning a new value to the element's `innerHTML` property.

## 5. What is `Object.entries()`?

`Object.entries()` returns an array containing the key-value pairs of an object.

## 6. What is an API?

API stands for Application Programming Interface. It allows different applications or systems to communicate and exchange data.

## 7. What is the difference between sequential and parallel?

Sequential execution runs tasks one after another, while parallel execution allows multiple tasks to run at the same time.

## 8. What is the difference between `getElementById()` and `querySelector()`?

`getElementById()` selects an element by its ID, while `querySelector()` can select an element using any valid CSS selector.

## 9. How do you write a promise that returns another promise?

A Promise can return another Promise from its `.then()` callback, allowing asynchronous operations to be chained.

## 10. What is the difference between `UNIQUE` and `PRIMARY KEY` in SQL?

Both prevent duplicate values, but a `PRIMARY KEY` uniquely identifies each row and cannot be `NULL`, while a table can have multiple `UNIQUE` constraints.

## 11. What is `appendChild()` in the DOM?

`appendChild()` is a DOM method used to add a node as the last child of a parent element.

## 12. What is the difference between a higher-order function and a callback function?

A higher-order function takes or returns a function, while a callback is the function passed to another function to be executed later.

## 13. What is the behavior of semantic and non-semantic tags in HTML?

Semantic tags describe the meaning of their content, while non-semantic tags like `<div>` and `<span>` do not describe its meaning.
