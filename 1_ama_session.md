## 1. What is the difference between find and rsync?
`find` searches for files/directories based on criteria, while rsync synchronizes files/directories between locations.

## 2. What is the difference between git log and git reflog?
`Git log` shows commit history, while `git reflog` shows the history of changes to Git references such as HEAD.

## 3. What is abstraction?
`Abstraction` hides implementation details and exposes only the essential features of an object.

## 4. What is the difference between pass and continue?
`pass` does nothing, while `continue` skips the current loop iteration and moves to the next iteration.

## 5. What is the difference between LIMIT and OFFSET?
`LIMIT` restricts the number of rows returned, while `OFFSET` skips a specified number of rows.

## 6. How can you concatenate two columns in SQL?
You can use CONCAT(column1, column2) or the || operator, depending on the database.


## 7. What is the difference between LEFT JOIN and RIGHT JOIN?
`LEFT JOIN` returns all rows from the left table, while `RIGHT JOIN` returns all rows from the right table.

## 8. Which command is used to connect to PostgreSQL?
The psql command is used to connect to PostgreSQL from the command line.
```
psql -U username -d database_name
```

## 9. What is the staging area in Git?
The staging area is where changes are placed before they are committed to the repository.

## 10. What is the difference between encapsulation and abstraction?
`Encapsulation` bundles data and methods together, while `abstraction` hides implementation details and shows essential functionality.

## 11. What is the purpose of the HAVING clause?
`HAVING` filters grouped results after GROUP BY, usually using aggregate functions.

## 12. What is the difference between append() and extend()?
`append()` adds one item to a list, while `extend()` adds all items from an iterable.

## 13. What is the difference between procedural programming and object-oriented programming?
Procedural programming focuses on functions and procedures, while object-oriented programming focuses on objects containing data and behavior.
