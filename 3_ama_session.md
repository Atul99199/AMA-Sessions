## 1. What is CSS Grid?

CSS Grid is a CSS layout system used to arrange elements in rows and columns. It makes it easier to create responsive page layouts.

## 2. What is the `rsync` command?

`rsync` is a command used to copy and synchronize files and folders between locations. It copies only the changed data, making it faster.

## 3. How to check if a character is an alphabet in Python?

We can use the `isalpha()` method to check whether a character is an alphabet.

## 4. How to open Firefox from the terminal?

We can open Firefox from the terminal by using the `firefox` command.

## 5. How to reverse a string using slicing?

We can reverse a string using slicing with `[::-1]`.


## 6. What is polymorphism?

Polymorphism means one method or function can behave differently depending on the object or data it works with.

## 7. What is a lambda function?

A lambda function is a small anonymous function written in a single line. It is useful for simple operations.

```python
square = lambda x: x * x
```

## 8. How to create an empty class?

An empty class can be created using the `class` keyword and `pass`.

```python
class Student:
    pass
```

## 9. What is the `grep` command in CLI?

`grep` is a command used to search for a specific word or pattern inside files or command output.

## 10. Does Python support method overloading?

Python does not support traditional method overloading like Java. We can achieve similar behavior using default arguments or `*args`.

## 11. What is the `LIKE` clause in SQL?

The `LIKE` clause is used to search for a specific pattern in a column. It commonly uses `%` and `_` as wildcards.

## 12. What is the order of CSS specificity?

CSS specificity is generally ordered as **inline styles > IDs > classes/attributes/pseudo-classes > elements/pseudo-elements**. Higher specificity rules take priority.

## 13. What is the full form of CSV?

CSV stands for **Comma-Separated Values**. It is a simple file format used to store tabular data.
