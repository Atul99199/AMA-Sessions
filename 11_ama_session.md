1. **What is the maximum token limit?**  
   The maximum token limit is the highest number of tokens a model can process or generate in a request, depending on its context window and output limit.

2. **What is RAG (Retrieval-Augmented Generation)?**  
   RAG is a technique in which AI retrieves relevant information from external sources, such as documents or databases, before generating an answer.

3. **What is Plan Mode?**  
   Plan Mode allows Claude to analyze a task and create a step-by-step plan before making changes to the code or executing actions.

4. **What is context management?**  
   Context management is the process of organizing, maintaining, and clearing relevant information in an AI conversation to help the model respond accurately and efficiently.

5. **What are the Discernment Lens and feedback loop?**  
   The Discernment Lens helps us critically evaluate AI-generated outputs, while the feedback loop uses feedback and results to improve future AI responses and performance.
