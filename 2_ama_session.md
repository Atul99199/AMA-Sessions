## 1. Why do we prefer relative positioning over absolute positioning in CSS?
Relative positioning keeps the element in the normal page layout while allowing small position changes. It is easier to manage than absolute positioning.

## 2. What is the Liskov Substitution Principle (LSP) in SOLID?
LSP means a child class should be able to replace its parent class without breaking the program.

## 3. What is the difference between sticky and fixed positioning in CSS?
`fixed` stays in the same place on the screen, while `sticky` scrolls normally until it reaches a specified position.

## 4. What is the `<sub>` tag in HTML, and when is it used?
The `<sub>` tag displays text slightly below the normal line. It is commonly used for chemical formulas like H₂O.

## 5. Which command can be used to check the audio driver in Linux?
The `lspci | grep -i audio` command can help check audio hardware in Linux.

## 6. What are the different layers of the CSS box model?
The CSS box model has four layers: **Content, Padding, Border, and Margin**.

## 7. What does `flex: 1` mean in CSS?
`flex: 1` allows an element to grow and take up the available space inside a flex container.

## 8. What is CSS specificity, and how does the specificity rule work?
Specificity decides which CSS rule is applied when multiple rules target the same element. More specific selectors have higher priority.

## 9. What is the difference between padding and margin in CSS?
Padding is space inside an element around its content, while margin is space outside the element.

## 10. What is the difference between `<section>`, `<article>`, and `<div>` in HTML?
`<section>` groups related content, `<article>` contains independent content, and `<div>` is a general container without special meaning.

## 11. Which command is used to change the current directory in Linux?
The `cd` command is used to change the current directory in Linux.

## 12. What is the `<pre>` tag in HTML, and when is it used?
The `<pre>` tag displays text exactly as written, including spaces and line breaks. It is useful for showing code or formatted text.

## 13. Why do we prefer relative units over absolute units in CSS?
Relative units like `%`, `em`, and `rem` adjust based on screen or parent size, making websites more responsive.
