## 1. What is a Promise?**

A Promise is an object that represents the result of an asynchronous operation, which can be successful or failed.

## 2. What are `async` and `await`?

`async` makes a function return a Promise, while `await` waits for a Promise to finish inside an async function.

## 3. How does the JavaScript engine work?

The JavaScript engine reads, parses, and executes JavaScript code using components like the call stack and memory heap.

## 4. What is `finally()` in promises?

`finally()` runs after a Promise is completed, whether it is fulfilled or rejected, and is commonly used for cleanup work.

## 5. What is `Promise.all()`?

`Promise.all()` runs multiple Promises together and returns the results when all of them are fulfilled; if one fails, the whole `Promise.all()` is rejected.

## 6. What is the event loop?

The Event Loop checks whether the call stack is empty and moves waiting asynchronous tasks to the call stack for execution.

## 7. What is inversion of control in JavaScript?

Inversion of control means giving another function control over when and how our callback function will be executed.

## 8. How does higher-order function chaining work?

Higher-order function chaining means calling functions one after another, where each function returns a value or function that can be used by the next function.

## 9. What are the Promise APIs?

Promise APIs are built-in methods like `Promise.all()`, `Promise.allSettled()`, `Promise.race()`, `Promise.any()`, `Promise.resolve()`, and `Promise.reject()` used to work with Promises.

## 10. What is the full form of AST?

AST stands for **Abstract Syntax Tree**. It is a tree-like structure that represents the code after it is parsed.

## 11. What is the full form of NVM?

NVM stands for **Node Version Manager**. It is used to install and switch between different Node.js versions.
